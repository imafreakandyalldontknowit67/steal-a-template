# Discoverability and public launch

## Current scope

This is a private GitHub repository, not a deployed website. The README, category navigation, descriptive repository metadata, and pack template are prepared for a future public catalog. No search ranking or indexing is promised.

## Repository positioning

- Name: `roblox-asset-packs`.
- Description: `Free Roblox asset packs for developers: UI kits, models, VFX, audio, and Luau systems. Studio-ready downloads with setup guides. In development.`
- Main README heading: `Free Roblox Assets & Asset Packs for Developers`.
- Relevant topics: roblox, roblox-studio, roblox-assets, asset-packs, game-assets, game-development, luau, ui-kit.

## Every finished pack

Use a specific title such as `Inventory UI Kit for Roblox Studio`, not an unexplained internal project name. Describe what is actually included, who it helps, supported inputs, dependencies, setup steps, and limitations. Add a real preview with descriptive alt text and a working versioned download link. Keep content original and avoid keyword stuffing or unsupported claims such as "best" or "most popular".

Link each released pack from its category and the root catalog. Publish useful pack pages, not dozens of empty keyword variations. The empty category directories here are organizational placeholders, not website pages to index.

## Future public download website

If the source stays private, publish only approved pack metadata, previews, and download files. Give each real pack a stable URL, unique page title and description, visible license, author, update date, and clear installation instructions. Keep empty categories and draft packs out of the public index. Add a sitemap containing only canonical public pages. Do not place private tokens in browser code.

A README cannot configure website title tags, canonical tags, structured data, robots rules, or a sitemap. Implement those when a website actually exists. Do not add fake ratings, fake download counts, or FAQ markup solely to chase rich results.
