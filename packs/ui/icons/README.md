# Steal a Template / Icons

Browse the extracted icon collections below. All artwork is provided as PNG files, including the collection named Vector Pack. Original icon filenames and internal artwork folders are preserved.

| Collection | Included files |
| --- | --- |
| [Free Icon Pack v3.1 (Basic)](free-icon-pack-v3.1-basic/) | 2,044 PNGs organized by category, icon, and size, plus the original license |
| [Exclusive 200 Vector Pack](exclusive-200-vector-pack/) | 228 PNGs in the original Totally folder |

Open an image to preview it or download the original file. Upload selected images through Roblox Studio and use the resulting asset IDs in your UI.
