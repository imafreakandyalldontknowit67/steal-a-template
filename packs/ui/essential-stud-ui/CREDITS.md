# Credits and permissions

## Design and artwork

This kit was built from user-supplied visual references. The existing asset record describes the artwork as reference-inspired and does not establish permission to redistribute the referenced design. Creator identification and distribution clearance still need to be recorded before release.

The two local artwork atlases were generated for this kit. [Generation prompts](assets/PROMPTS.md) and the [asset manifest](assets/manifest.json) document the source artwork, uploaded Roblox image IDs, and avatar IDs. Seller source files and reference media are not bundled.

## Dependencies

Roblox-hosted images and avatar thumbnails must be accessible in the destination experience. No audio files are included; the documented sound groups accept audio supplied by the consuming game.

## License

No reuse or redistribution license has been selected for this pack. Generated artwork does not by itself establish permission for the reference-inspired design. Add the chosen license and confirmed creator permissions before public distribution.
