# Discord artwork

The profile image was generated with the built-in image generation tool. It is saved as `assets/profile.png` and was uploaded directly as the server icon and bot avatar.

## Profile generation prompt

Create a square Discord server profile picture for 'Steal a Template', a free Roblox developer asset library. Match a retro Roblox studded plastic aesthetic: charcoal #171A1D background, acid lime #B6FF00 main color, cyan and yellow accents. A single cheerful classic blocky yellow builder head and blue torso peeking over and carrying one bright lime green miniature UI window as loot. Simple 3D toy plastic forms, two black eyes and small smile, bold thick black outlines, modest bevels, square studs on the UI window frame, red square close button with white X in the upper right. No lettering, no words, no tiny details. Strong clean silhouette clearly recognizable at 48 pixels. Centered composition occupying central 75 percent of canvas, generous safe margins so circular avatar crop won't cut off the head or green panel. Dark background fully opaque. Playful old Roblox aesthetic matching a chunky lime and charcoal banner. Premium illustrated game-icon finish, no official logo, no additional characters or clutter.

## Channel banners and onboarding icons

The nine banners and eight onboarding icons extend the existing editable SVG brand system. They use the palette in `assets/branding/tokens.json` at the repository root.

Banners: 1200 × 320. Icons: 128 × 128 with transparent backgrounds. SVGs were rendered with resvg using installed system fonts. The PNGs are the uploaded artifacts; the SVGs remain editable. Banner text uses Arial and Arial Black fallbacks.

No external stock artwork or seller assets are included in this folder. The original repository hero banner remains unchanged.
